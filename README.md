# 🚌 Online Bus Ticket Reservation System

An online platform for users to search, book, and manage bus tickets easily. The system offers a user-friendly interface for travelers and an admin panel for operators to manage buses, routes, and bookings.

---

## 📌 Project Features

### 👤 User Features
- Register and login securely
- Search buses by route and date
- View available seats and make bookings
- View and cancel existing bookings

### 🛠 Admin Features
- Add, update, and delete bus details
- Manage routes and travel schedules
- View all bookings and user info
- Monitor seat availability

---

- **Backend**: PHP (or any language you're using)
